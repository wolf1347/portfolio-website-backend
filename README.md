# Portfolio Website Backend

A clean, minimal ASP.NET Core Web API built with .NET 10. This project serves as the backend for my personal portfolio website.

## Tech Stack
- **Framework:** .NET 10 (ASP.NET Core)
- **Language:** C#
- **Documentation:** OpenAPI (Swagger)

## Getting Started

### Prerequisites
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

### Installation
1. Clone the repository
2. Restore dependencies:
   ```bash
   dotnet restore
   ```
3. Build the project:
   ```bash
   dotnet build
   ```
4. Run the application:
   ```bash
   dotnet run --project portfolio-website-backend
   ```

The API will be available at `http://localhost:5291` (or the port specified in `Properties/launchSettings.json`).
